# Lab 08 — SQL Server and PostgreSQL hardening and audit

Assess a default SQL Server and a default PostgreSQL with the same 12 checks each, harden both with idempotent
scripts, prove the audit trail, and show unsafe dynamic SQL next to its parameterized fix. Everything that needs a
database runs in GitHub Actions against containers with synthetic data; it has never been run on a production server.

Documentation follows in `docs/` and the write-ups.
